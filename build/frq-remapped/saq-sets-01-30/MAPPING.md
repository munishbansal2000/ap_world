# SAQ Sets 01–30 — Source Mapping & Verification Notes

All 30 sets built for the **Fall 2026 CED** SAQ format: 3 required SAQs per set —
Q1 secondary text, Q2 primary text, Q3 non-text (map/chart/image) — each with
parts A/B/C (1 point each), directions and attribution in the Barron's-test
format pattern (format only; all content re-conceived).

## Source → set mapping

"Source SAQ" = the old-format Barron's/PR book SAQ whose TOPIC inspired the set.
Every stimulus was rewritten fresh and every question redesigned; no book
wording, selection, or arrangement was retained. Pre-1900 primary excerpts are
quoted or closely adapted from the public-domain originals; post-1929 sources
are paraphrased and labeled as such; Q1 secondary passages are original
historian-style interpretations (no fabricated historian names).

## Coverage

- **Units:** U1×3, U2×3, U3×4, U4×4, U5×4, U6×4, U7×3, U8×3, U9×2 = 30 sets,
  roughly proportional to exam weights (U3–U6 at 12–15% get 4 each; others 2–3).
- **Reasoning processes:** comparison ×10 (sets 04, 05, 07, 10, 17, 19, 21, 23,
  24, 26); causation ×11 (sets 02, 11, 12, 13, 14, 15, 16, 22, 25, 27, 29);
  continuity and change ×9 (sets 01, 03, 06, 08, 09, 18, 20, 28, 30).
- **Themes:** ECN 8, GOV 8, CDI 5, ENV 3, SIO 3, TEC 3.
- **Q3 types:** 9 maps, 19 images/photos/paintings/posters, 2 charts.

## Q3 image verification

Every `stimulus_url` was verified live 2026-10-02: HTTP 200 with an image
content-type, resolved from Wikimedia Commons (Special:FilePath redirect or a
search-returned upload.wikimedia.org locator used byte-for-byte). **Zero
unverified URLs shipped.**

License basis: all files are hosted on Wikimedia Commons under free licenses.
Pre-1929 works (paintings, 1502/1154 maps, 1898 cartoon, Lissitzky 1919 poster,
Cranach 1529 portrait, Delacroix 1830) are public domain by age; FSA/Hine
photographs and the NASA Apollo photo are PD-USGov; the Opte internet map is
CC-licensed; user-created maps/charts (Song, Mali, plague, Mongol, Ottoman,
Zheng He, triangular trade, Europe 1919, Keeling Curve, colonization GIF) and
modern photographs (dhow, Versailles, Dejima, Iron Bridge, suffragettes, Canton
factories, Nkrumah, Berlin Wall, container ship) are Commons-hosted free-license
files. **Caveat:** license fields were not re-read per file (the Commons API
was unreachable from this environment); confirm the license tab on each file
page before commercial use.

## Set-28 topic note

The original plan (Long March map) was dropped after no verifiable
Commons-hosted Long March map or PD/CC China-1930s photograph could be found.
The set was re-conceived as the Space Race (U8, TEC, continuity and change)
with a verified NASA public-domain image. No unverified visual was substituted.
